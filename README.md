## 这是什么

一个 Android 悬浮窗工具：**导入 MIDI 谱面 → 在屏幕上实时提示下一个音该按哪个键、要不要升半音、要不要变调**。

主要给 **《三角洲行动》里的口琴小游戏**用，也适用于任何"看着谱子按琴"的场景（音游、口琴练习）。它的定位是**视觉辅助**：不联网、不读游戏内存、不注入、不修改游戏数据，只是在你屏幕上画提示。

```
选 MIDI ──▶ 解析音符 ──▶ 映射成简谱轨位 ──▶ 悬浮窗按时间轴落 note
             (ktmidi)      (1~8 轨 + 变调/半音提示)
```

## 功能

- **MIDI 解析**：支持标准 MIDI（PPQ），自动处理变速（Tempo 事件）、力度 0 的 note-off；损坏文件会提示而不是崩溃。
- **悬浮窗提示**：8 条轨 + 4 种功能提示（半音 / 升调 / 自然 / 降调），判定线与节奏圈两种呈现方式可分别设置。
- **一次性校准**：把校准图拖到和游戏界面重合、双指缩放对齐，位置和缩放都会记住，下次直接开播。
- **资源包**：内置一套 Phigros 风格皮肤，也支持导入自制 zip 皮肤（见下）。
- **设置码**：把整套视觉设置编码成一段短码，跨设备分享（`A` 开头是高级设置，`B` 开头是基础设置）。
- **样式预览**：高级设置页底部可以实时预览两条线/音符/指示圈长什么样（竖屏下会等比缩小，想看点"真实大小"就横过来）。
- **其他**：深/浅色主题、悬浮窗背景透明度、打击特效，以及藏在菜单里的"今日人品"。

## 快速开始

1. **安装**：到 [Releases](https://github.com/MooCen/Harmonica-Indicator/releases) 下载 APK 安装（Android 8.0+）。
2. **给权限**：首次启动 → 侧边栏「软件权限设置」→ 授予**悬浮窗**权限（Android 13+ 建议顺便给通知权限，用于常驻通知）。
3. **选谱**：点「选择 Midi 文件」，或者在文件管理器里用「用其他应用打开」/ 微信、QQ 的「分享到」直接把 `.mid` 交给本应用。
4. **启动悬浮窗**：点「启动悬浮窗」，屏幕上会出现校准图。
5. **校准**：把图拖到和游戏里的口琴界面重合（双指缩放），对齐后点「隐藏校准界面」。
6. **开始**：点「就绪时，点击此处开始」，悬浮窗就不再拦截触控，跟着谱面落 note。
7. **停止**：回到 App 点「关闭悬浮窗」，或点通知回到 App 再关。

> 悬浮窗是**强制横屏**的，校准和演奏时请横着拿手机。

## 提示符号怎么看

提示位置对应的是**简谱音级**，不是琴上的物理孔位——具体哪个孔看你自己的琴。

| 标记 | 含义 |
|---|---|
| `1` – `7` | 中音区：do re mi fa sol la si |
| `8` | 高音 1（C6），只有这一个音会用到 8 号轨 |
| 后缀 `.` | 低音区（如 `5.`） |
| 后缀 `'` | 高音区（如 `3'`） |
| 后缀 `''` | 双高音（只有 `1''`） |
| 前缀 `#` | 升半音（如 `#3`） |

悬浮窗上的**功能提示**会提前告诉你"接下来要升半音 / 升调 / 回中 / 降调"，不用自己数。

## 资源包

内置皮肤：**高仿官皮新版** — 作者 `fkh（B站 苏八拉稀）`。

想自己做一个：

```
my_pack.zip
└── my_pack/            ← 公共顶层目录可有可无，会自动剥掉
    ├── info.yml
    ├── click.png       click_mh.png      (Tap)
    ├── drag.png        drag_mh.png       (Drag)
    ├── flick.png       flick_mh.png      (Flick)
    ├── hold.png        hold_mh.png       (Hold)
    └── hit_fx.png                        (打击特效图集)
```

`info.yml`（只支持顶层 `key: value`）：

| 字段 | 示例 | 说明 |
|---|---|---|
| `name` | `"我的皮肤"` | 显示名 |
| `author` | `你的名字` | 作者 |
| `description` | `说明` | 简介 |
| `hitFx` | `[7, 6]` | 特效图集切分：列数, 行数 |
| `colorPerfect` | `0xFCFDB4` | 判定线 / 普通圈颜色 |
| `colorGood` | `0x78D8FC` | 双押圈颜色 |
| `hitFxDuration` / `hitFxScale` / `holdAtlas` | — | 预留字段，**当前版本还不生效** |

- `*_mh.png` 是"双押"版本的图，没有就缺一张；缺图会跳过，不会崩。
- 导入：设置页 →「导入资源包」→ 选 zip。包名 = zip 文件名，重名会被拒绝。
- 资源包解压在 `Android/data/com.moocengg.harmonica_indicator/files/resource_packs/`，卸载 App 会一起没。
- 音频文件（`*.ogg`）目前**不会被播放**，放进去也没用。

## 设置码

在「指示器高级设置」右上角的 ⇄ 按钮里，可以把当前视觉设置导出成一段短码：

- `A` 开头：高级设置（透明度区间、两条线的速度/类型/音符样式/是否反转）
- `B` 开头：基础设置（下落速度、音符大小、圈收缩速度、提前量、特效大小）

复制给别人，对方粘贴进去就能复刻你的手感。**注意：字段是定长的，同一个码只对相同版本的 App 有意义。**

## 常见问题

**为什么要悬浮窗权限？**
因为要盖在游戏上面画提示。没有这个权限，App 只能在后台干瞪眼。

**为什么不播放声音？**
目前只做视觉提示。谱面里的 `.ogg` 音效还没有接播放逻辑。

**会不会被当成外挂？**
本应用不联网、不读其他应用的内存、不注入、不改游戏文件，只做两件事：读你给的 MIDI、在屏幕上画提示。判定和成绩完全由游戏自己算。作者就是因为被误判成外挂下架过视频，所以这条红线会一直守着。

**为什么我的谱子解析不出来？**
只支持标准 MIDI（PPQ 格式）。SMPTE 时间码的 MIDI 不支持；文件损坏会提示"解析失败"而不是崩溃。

**音符太大 / 太小 / 太快？**
「指示器高级设置」里可以分别调两条线的下落速度、音符缩放、圈收缩速度与提前量，调完看底部预览，满意了再开播。

**预览看着好小？**
预览是等比缩放的（占屏比例和真机一致），竖屏下自然显小。横过来看会更接近真实观感。

**校准总是对不齐？**
先点「重置校准界面位置」，再重新拖。校准图不用和游戏界面完全一样大，只要**判定点和游戏里的键位重合**就行。
